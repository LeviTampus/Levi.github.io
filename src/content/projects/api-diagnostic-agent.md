## Why I built it

I wanted to learn how agents work, and I leaned on AI to write most of it. That
turned out to be the lesson.

## What it does

It investigates API and integration issues: it runs diagnostics, searches
troubleshooting notes, and returns a report of what to try next.

## How it's built

A LangGraph agent with tool calling and retrieval. Most of the code was
AI-generated, which is where it went wrong.

## Where it stands

Abandoned. The code grew past what I could explain, and I couldn't trust changes
I didn't understand. I started over from Python fundamentals, which led to the
watchlist agent and the RAG work. The old build is still up if you want to see
it.
